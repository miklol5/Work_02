# 🌿 ระบบจำแนกประเภทขยะอัจฉริยะเพื่อการจัดการสิ่งแวดล้อมในพื้นที่สาธารณะ
### Smart Public Waste Sorting AI System

ระบบตรวจจับและจำแนกประเภทขยะแบบเรียลไทม์ผ่านกล้อง (Webcam / มือถือ) พร้อมระบบแนะนำการทิ้งขยะตามมาตรฐาน 4 สีถังขยะของไทย คำนวณผลกระทบต่อสิ่งแวดล้อม (ลดก๊าซเรือนกระจก CO₂) ระบบเสียงพูดแนะนำภาษาไทย และหน้าแดชบอร์ดสถิติสำหรับผู้ดูแลพื้นที่สาธารณะ

---

## ✨ ฟีเจอร์เด่นของระบบ

1. **การตรวจจับสดผ่านกล้อง (Real-time AI Detection):**
   * ตรวจจับขยะและตีกรอบ Bounding Box พร้อมค่าความมั่นใจ (Confidence Score)
   * ปรับระดับความไว AI ได้แบบเรียลไทม์ผ่านสไลเดอร์
   * ทำงานได้ไม่จำกัดรอบ ไม่ต้องกดถ่ายภาพ (Continuous Stream)

2. **ระบบการ์ดแนะนำการทิ้งขยะอัจฉริยะ (Smart Guidance Card):**
   * แสดงประเภทขยะและสีถังขยะเป้าหมายขนาดใหญ่ชัดเจน:
     * 🟡 **ถังสีเหลือง (ขยะรีไซเคิล):** ขวดพลาสติก, กระป๋องโลหะ, แก้ว, กระดาษ, ลังกระดาษ
     * 🟢 **ถังสีเขียว (ขยะอินทรีย์ / เปียก):** เศษอาหาร, เปลือกผลไม้, ขยะชีวภาพ
     * 🔴 **ถังสีแดง/ส้ม (ขยะอันตราย / ติดเชื้อ):** ถ่านไฟฉาย, ขยะอิเล็กทรอนิกส์ (E-waste), หน้ากากอนามัย
     * 🔵 **ถังสีน้ำเงิน (ขยะทั่วไป):** ซองขนม, ถุงพลาสติก, ขยะที่ไม่สามารถรีไซเคิลได้
   * **คำแนะนำเพื่อสิ่งแวดล้อม (Eco-Tips):** เช่น *"เทของเหลวออกและบีบขวดให้แบนก่อนทิ้ง"*

3. **ระบบเสียงพูดแนะนำภาษาไทย (Thai Voice Guidance):**
   * แจ้งเตือนด้วยเสียงพูดภาษาไทยอัตโนมัติ เช่น *"ขวดน้ำพลาสติก ทิ้งลงถังขยะรีไซเคิลสีเหลืองค่ะ"*
   * มีปุ่มเปิด-ปิดเสียงที่มุมบน

4. **รองรับการใช้งานบนมือถือ (Mobile Friendly):**
   * รองรับ Responsive Design ปรับหน้าจอแนวตั้งอัตโนมัติ
   * เปิด **กล้องหลัง (Environment Facing)** เป็นค่าเริ่มต้นทันที พร้อมปุ่มสลับกล้องหน้า/หลัง
   * มีปุ่ม **"เปิดบนมือถือ"** แสดง **QR Code** สำหรับสแกนเข้าใช้งานผ่านสมาร์ตโฟนในวง Wi-Fi เดียวกัน

5. **แดชบอร์ดสถิติเพื่อการจัดการสิ่งแวดล้อม (`/dashboard`):**
   * สรุปจำนวนชิ้นขยะที่คัดแยกสะสมประจำวัน
   * คำนวณปริมาณการลดการปล่อยก๊าซคาร์บอนไดออกไซด์สะสม (kg CO₂e Saved)
   * กราฟโดนัทแสดงสัดส่วนขยะตาม 4 สีถัง
   * กราฟแท่งแสดงความถี่การทิ้งขยะรายชั่วโมง (Hourly Trends) เพื่อช่วยเจ้าหน้าที่วางแผนรอบเก็บขยะ
   * ตารางบันทึกประวัติการตรวจจับล่าสุดพร้อมเวลาและระดับความมั่นใจ

## 🚀 วิธีเปิดใช้งานระบบ

### วิธีที่ 1: ดับเบิลคลิกไฟล์ `run.bat`
เพียงดับเบิลคลิกที่ไฟล์ **`run.bat`** ในโฟลเดอร์นี้ ระบบจะเปิด Web Server ขึ้นมาโดยอัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / PowerShell
```bash
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

## 🌐 ลิงก์เข้าใช้งาน

* **หน้ากล้องตรวจจับขยะ:** [http://localhost:8000](http://localhost:8000)
* **หน้าแดชบอร์ดสถิติ:** [http://localhost:8000/dashboard](http://localhost:8000/dashboard)
* **การเปิดบนมือถือ:** เชื่อมต่อ Wi-Fi เดียวกันกับคอมพิวเตอร์ แล้วสแกน QR Code จากปุ่ม "เปิดบนมือถือ" บนหน้าเว็บ

## 📁 โครงสร้างไฟล์ในโปรเจกต์

```
Work_02/
├── static/
│   └── js/
│       └── app.js             # ควบคุมกล้อง, สตรีมมิ่ง, Bounding Box, เสียงพูดภาษาไทย
├── templates/
│   ├── index.html             # หน้าเว็บหลักส่องกล้องตรวจจับและแสดงการ์ดสีถังขยะ
│   └── dashboard.html         # หน้าแดชบอร์ดกราฟสถิติ Chart.js และประวัติการคัดแยก
├── app.py                     # เซิร์ฟเวอร์ FastAPI และ REST API endpoints
├── classifier.py              # โหลดโมเดล YOLO และระบบแมปประเภทขยะ 4 สีถัง
├── database.py                # ระบบฐานข้อมูล SQLite จัดเก็บประวัติและคำนวณสถิติ
├── waste_management.db        # ไฟล์ฐานข้อมูล SQLite (สร้างอัตโนมัติ)
├── waste_yolov8.pt            # โมเดล YOLOv8 สำหรับจำแนกขยะ
├── requirements.txt           # รายการแพ็กเกจที่ต้องใช้งาน
└── run.bat                    # สคริปต์คลิกเดียวสำหรับเปิดรันระบบ
```

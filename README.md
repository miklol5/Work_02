# 🌿 ระบบจำแนกประเภทขยะอัจฉริยะเพื่อการจัดการสิ่งแวดล้อมในพื้นที่สาธารณะ
### Smart Public Waste Sorting AI System

ระบบตรวจจับและจำแนกประเภทขยะผ่านกล้องสมาร์ตโฟนและคอมพิวเตอร์ ขับเคลื่อนด้วย Deep Learning **Ultralytics YOLOv8** พร้อมระบบแนะนำการทิ้งขยะตามมาตรฐาน 4 สีถังขยะของไทย คำนวณผลกระทบต่อสิ่งแวดล้อม (ลดก๊าซเรือนกระจก CO₂) ระบบเสียงพูดแนะนำภาษาไทย และหน้าแดชบอร์ดสรุปสถิติสำหรับผู้ดูแลพื้นที่สาธารณะ

---

## ✨ ฟีเจอร์เด่นของระบบ

1. **การถ่ายภาพสแกนขยะผ่านกล้อง (Photo Capture & AI Scan):**
   * ถ่ายภาพผ่านกล้องมือถือ/เว็บแคม ตรวจจับและตีกรอบ Bounding Box พร้อมค่าความมั่นใจ (Confidence Score)
   * ย่อภาพอัตโนมัติก่อนประมวลผล ทำให้ได้ความเร็วระดับเสี้ยววินาที (< 0.2 วินาที)

2. **ระบบการ์ดแนะนำการทิ้งขยะอัจฉริยะ (Smart Guidance Card):**
   * แสดงประเภทขยะและสีถังขยะเป้าหมายขนาดใหญ่ชัดเจนตามมาตรฐาน 4 สี:
     * 🟡 **ถังสีเหลือง (ขยะรีไซเคิล):** ขวดพลาสติก, กระป๋องโลหะ, แก้ว, กระดาษ, ลังกระดาษ
     * 🟢 **ถังสีเขียว (ขยะอินทรีย์ / เปียก):** เศษอาหาร, เปลือกผลไม้, ขยะชีวภาพ
     * 🔴 **ถังสีแดง/ส้ม (ขยะอันตราย / ติดเชื้อ):** ถ่านไฟฉาย, ขยะอิเล็กทรอนิกส์ (E-waste), ยาหมดอายุ
     * 🔵 **ถังสีน้ำเงิน (ขยะทั่วไป):** ซองขนม, กล่องโฟม, ถุงพลาสติกเปื้อน
   * คำแนะนำเพื่อสิ่งแวดล้อม (Eco-Tips) เช่น *"บีบขวดให้แบนก่อนทิ้ง"*

3. **ระบบเสียงพูดแนะนำภาษาไทย (Thai Voice Guidance):**
   * แจ้งเตือนด้วยเสียงพูดภาษาไทยอัตโนมัติ เช่น *"ขวดน้ำพลาสติก ทิ้งลงถังขยะรีไซเคิลสีเหลืองค่ะ"*

4. **แดชบอร์ดสถิติเพื่อการจัดการสิ่งแวดล้อม (`/dashboard`):**
   * สรุปจำนวนชิ้นขยะที่คัดแยกสะสม
   * คำนวณปริมาณการลดการปล่อยก๊าซคาร์บอนไดออกไซด์สะสม (kg CO₂e Saved)
   * กราฟวงกลมแสดงสัดส่วนขยะตาม 4 สีถังขยะ
   * ตารางบันทึกประวัติการตรวจจับล่าสุดแบบเรียลไทม์

5. **สไลด์นำเสนอผลงาน (`/presentation`):**
   * หน้าเว็บสไลด์นำเสนอโครงงาน 10 สไลด์ พร้อมปุ่มดาวน์โหลดไฟล์ `.pptx` (Canva Ready)

## 🚀 วิธีการเปิดใช้งาน (1 คลิก)

1. ดับเบิ้ลคลิกไฟล์ **`START_SYSTEM.bat`** (หรือไฟล์ **`START_SMART_WASTE_AI.bat`** บน Desktop)
2. ระบบจะเริ่มเซิร์ฟเวอร์ AI และสร้างลิงก์ **HTTPS ความเร็วสูง** พร้อมแสดง **QR Code** บนหน้าจอทันที
3. นำมือถือมาสแกน QR Code เพื่อเปิดใช้งานระบบสแกนขยะได้ทันทีจากทุกที่!
